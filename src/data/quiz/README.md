# 퀴즈 데이터 관리

이 디렉터리의 JSON이 퀴즈의 원본입니다. 과정 디렉터리 이름이 과정 ID이며,
챕터 URL의 마지막 번호는 `order`에서 가져옵니다. 각 과정의 `order`는 1부터
빠짐없이 이어져야 합니다.

기존 챕터에 문항을 추가할 때는 해당 JSON의 `questions` 배열에 문항 하나만
추가합니다. 문항 수나 과정 합계는 따로 수정하지 않습니다.

## 기존 과정에 챕터 추가

같은 과정의 `chapters`에서 파일 하나를 복사하고 내용을 구분할 수 있는 고유한
파일명으로 바꾼 뒤 다음 값과 문항만 수정합니다.

- `order`: 과정 안에서 표시할 순서이자 URL에 사용하는 번호
- `title`: 화면에 표시할 이름
- `questions`: 문항 목록

객관식은 `choices`와 `answers`, 주관식은 `answer`를 사용합니다. 객관식 정답은
`A`부터 `F`까지의 배열이며 실제 선택지 범위 안에 있어야 합니다. 주관식 이미지는
`public/img`에 두고 `/img/...` 경로로 참조합니다.

## 과정 추가

과정 ID로 사용할 디렉터리를 만들고 `order`와 `label`이 있는 `course.json`, 하나
이상의 챕터 JSON을 추가합니다. 과정과 챕터는 빌드 시 자동 발견되므로 코드에
별도로 등록하지 않습니다. 과정 표시 순서는 중복될 수 없습니다. 과정별 챕터 표시
순서는 중복되거나 중간 번호가 빠질 수 없습니다.

## 검증

`npm run build`를 실행하면 Content Collections 스키마가 모든 과정, 챕터,
문항 형식과 객관식 정답 범위를 검사합니다. 문항·챕터·과정 합계와 내비게이션은
검증된 데이터에서 자동 계산됩니다.
